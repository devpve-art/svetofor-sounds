# Звуки датчика «Светофор-бокс»

Набор звуков, который прибор (ESP32-S3) скачивает сам при первом включении по HTTPS:
`https://raw.githubusercontent.com/<владелец>/svetofor-sounds/main/sounds/`.

- `sounds/ДД/ННН.mp3|wav` — файлы как на SD-карте DFPlayer: 02 — оповещения датчика, 03 — системные полные,
  04 — системные короткие. ДД = 01..99, ННН = 001..255, не более 254 файлов.
- `sounds/manifest.txt` — список файлов с длиной и crc32; прибор качает по нему и сверяет.

## Как заменить набор

1. Положить файлы в `sounds/` (папки `02`, `03`, `04`…; лучше готовые после «Сжать звуки…» в прошивальщике).
2. `python make_manifest.py` — пересоберёт манифест, проверит имена и число файлов; строка `ver` меняется сама.
3. `git add -A && git commit -m "Новый набор звуков" && git push`.

Приборы, которые уже скачали набор, его не перекачивают: повторная загрузка только из меню прибора.
Git LFS не использовать (прибор получил бы файл-ссылку вместо звука). `.gitattributes` (`* -text`) не даёт Windows менять байты.
